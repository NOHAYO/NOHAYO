# Tour de Israel – דמו לאתר משופר

אב-טיפוס להצגה: אתר סטטי (HTML + CSS + JavaScript) שמרגיש כמו אתר אמיתי ועובד לגמרי מקומית.
אין בו שרת, תשלום אמיתי או חיבור לאתר החי, והוא עובד גם בלי אינטרנט.
כל הנתונים בדויים: שמות מורי הדרך, מספרי הרישיון, חוות הדעת והמחירים.

## איך מריצים (לחיצה כפולה)

| מערכת | מה לפתוח |
|---|---|
| **Windows** | `start-windows.bat` |
| **Mac** | `start-mac.command` (בפעם הראשונה: קליק ימני ← Open) |
| **Linux** | `start-linux.sh` |

הקובץ מפעיל שרת מקומי קטן ופותח את הדפדפן. לסגירה סוגרים את החלון השחור.
אם אין Python במחשב, נפתח במקום זה `index.html` ישירות, וגם כך הכול עובד.

אפשרות ידנית: `python3 serve.py`, או פשוט לחיצה כפולה על `index.html`.

## מה עובד כמו באתר אמיתי

כל מה שעושים בדמו **נשמר בדפדפן** (localStorage), ונשאר שם גם אחרי רענון וסגירה:

- **הזמנה מלאה:** בחירת מועד ומשתתפים ← פרטים ← תשלום (כרטיס או ביט) ← אישור עם מספר הזמנה.
  - **התשלום מדומה:** כרטיס בדיקה קבוע ונעול, אז אי אפשר להזין כרטיס אמיתי, ושום דבר לא נשלח.
  - **המקומות הפנויים מתעדכנים:** מועד מלא מסומן "אזל".
- **ההזמנות שלי** (`my-bookings.html`): ספירה לאחור, ניווט ב-Waze, הוספה ליומן (קובץ ‎.ics), שיתוף בוואטסאפ, וביטול עצמי עם חישוב החזר לפי מדיניות הביטול.
- **מועדפים:** לב על כל סיור. המונה מופיע בכותרת.
- **טופס סיור מותאם, טופס צור קשר וחוות דעת:** הכול נשמר. חוות דעת שנשלחה מופיעה מיד בעמוד הסיור.
- **ממשק המשרד** (`admin.html`): מה בעל העסק רואה.
  - **סקירה:** הזמנות והכנסות צפויות ל-30 יום, ותפוסה לכל יציאה.
  - **לידים:** בקשות לסיור מותאם, עם שינוי סטטוס.
  - **הודעות וחוות דעת:** עם התראה על דירוג נמוך.
  - **נתוני דוגמה:** הממשק מתחיל עם נתוני דוגמה של "לקוחות אחרים", כדי שלא יהיה ריק.
- **איפוס:** הכפתור "איפוס נתוני הדמו" בממשק המשרד מחזיר הכול למצב ההתחלתי. כדאי ללחוץ עליו לפני שמציגים.

### עבודה בלי אינטרנט

- הגופן (Heebo) והאיורים כלולים בתיקייה, כך שאין תלות ברשת.
- מה שכן צריך אינטרנט: המפה המוטמעת, שבלי חיבור מוחלפת בכרטיס עם הכתובת, וקישורי וואטסאפ, Waze והרשתות החברתיות.

## הצגה מומלצת לחבר (5 דקות)

1. **עמוד "מה השתפר"** (הקישור בבאנר העליון): ההשוואה של לפני ואחרי.
2. **דף הבית:** טיולים שעברו לא מוצגים. אחר כך מתג לאנגלית וחזרה.
3. **עמוד טיול:** הזמנה מלאה עד האישור, ואחר כך "ההזמנות שלי".
4. **סימולציית חוות דעת** (`review.html`): דירוג נמוך.
5. **ממשק המשרד:** ההזמנה, הליד וחוות הדעת מופיעים שם.

## איך עורכים את הנתונים: `assets/js/data.js`

כל התוכן נמצא בקובץ אחד. פותחים אותו בכל עורך טקסט (למשל VS Code או Notepad++).

- **פרטי העסק** (`SITE`): טלפון, מספר וואטסאפ (בפורמט `972501234567`), דוא״ל, שעות מענה ורשתות חברתיות.
- **מורי דרך** (`GUIDES`): שם, ביוגרפיה, מספר רישיון, שפות, ותק, זמן תגובה (בדקות) ותחומים.
- **טיולים** (`TRIPS`): כותרת, תיאור, מחיר, אזור, סוג, שפות, נקודת מפגש (כולל קואורדינטות), מה כלול, גודל קבוצה ותאריכים.
- **חוות דעת** (`REVIEWS`) ו**כתבות** (`ARTICLES`).

טקסט דו-לשוני נכתב כך: `{ he: 'עברית', en: 'English' }`.

### תאריכים

תאריכים נכתבים כ-`day(14)`, כלומר 14 ימים מהיום, כך שהדמו תמיד עדכני. מספר שלילי (`day(-30)`) הוא תאריך שעבר. אפשר גם תאריך קבוע: `'2026-12-10'`.
טיול שכל התאריכים שלו עברו לא מוצג ברשימות. בדמו יש שניים כאלה: "סיור סליחות" ו"חול המועד סוכות".

### תמונות

הדמו משתמש באיורים מקומיים מהתיקייה `assets/img/scenes`, למשל `petra` או `jerusalem-walls`.
כדי להחליף אותם בתמונות אמיתיות (מומלץ להשתמש בתמונות מהסיורים של החבר):

1. מעתיקים את התמונות לתיקייה `assets/img/photos/`.
2. ב-`data.js`, בשדה `images` של הטיול, כותבים את הנתיב: `'assets/img/photos/petra-1.jpg'`.

אפשר גם מזהה של תמונה מ-Unsplash, אבל אז היא תיטען רק כשיש אינטרנט.

### טקסטים של הממשק

כל הכפתורים, הכותרות וטקסטי עמוד "מה השתפר" נמצאים ב-`assets/js/i18n.js`, בעברית ובאנגלית.
`region`, `type`, `interests` וכדומה הם מילים קבועות באנגלית, והתוויות שלהן מוגדרות שם.

## העלאה לאירוח חינמי ושליחת קישור

**Netlify Drop:** נכנסים ל-https://app.netlify.com/drop, גוררים את **התיקייה `tourdeisrael-demo` כולה**, ומקבלים קישור לשליחה.

**GitHub Pages:** מעלים את **התוכן** של התיקייה למאגר חדש, ואז **Settings ← Pages**: Branch `main`, תיקייה `/ (root)`.

> לכל מי שנכנס לקישור יש "חנות" נפרדת: ההזמנות שלו נשמרות רק בדפדפן שלו.

## מבנה התיקיות

```
tourdeisrael-demo/
├── start-windows.bat / start-mac.command / start-linux.sh   ← הפעלה בלחיצה כפולה
├── serve.py                         ← שרת מקומי קטן (Python)
├── index.html … admin.html          ← 13 עמודים (שלד דק, התוכן נבנה ב-JS)
├── assets/css/style.css, fonts.css  ← עיצוב וגופן מקומי
├── assets/fonts/                    ← Heebo (רישיון SIL OFL)
├── assets/img/scenes/               ← איורי היעדים (SVG)
├── assets/js/data.js                ← כל הנתונים
├── assets/js/i18n.js                ← כל הטקסטים בעברית ובאנגלית
├── assets/js/store.js               ← "שרת" מדומה: הזמנות, לידים, חוות דעת, מועדפים
├── assets/js/app.js                 ← כותרת, תחתית, באנר דמו, מתג שפה ורכיבים משותפים
└── assets/js/pages/*.js             ← לוגיקה לכל עמוד
```

## נגישות ונייד

- **כיוון וזום:** `dir="rtl"` בעברית ו-`ltr` באנגלית, עם CSS מבוסס logical properties. אין חסימה של הגדלת תצוגה.
- **ניווט מקלדת:** קישור "דלג לתוכן", ניווט מלא במקלדת (כולל לשוניות בממשק המשרד עם חיצים) ומסגרת פוקוס בולטת.
- **סמנטיקה וטפסים:** תגיות סמנטיות, `alt` לתמונות, ותוויות והודעות שגיאה נגישות בטפסים.
- **קוראי מסך:** הודעות מערכת ומונים מוכרזים.
- **ניגודיות ותנועה:** ניגודיות ברמת WCAG AA, ותמיכה ב-`prefers-reduced-motion`.

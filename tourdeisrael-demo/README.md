# Tour de Israel – דמו לאתר משופר

אב-טיפוס להצגה בלבד: אתר סטטי (HTML + CSS + JavaScript), בלי שרת, בלי תשלום ובלי חיבור לאתר החי.
כל הנתונים בדויים: שמות מורי הדרך, מספרי הרישיון, חוות הדעת והמחירים.

## איך מריצים

**הכי פשוט:** לפתוח בדפדפן את הקובץ `index.html` בלחיצה כפולה.

**עם שרת מקומי** (מומלץ, כי המפה וחלק מהקישורים עובדים טוב יותר):

```bash
cd tourdeisrael-demo
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

אפשר גם `npx serve .` למי שמותקן אצלו Node.

## מה יש בדמו

| עמוד | קובץ |
|---|---|
| דף הבית | `index.html` |
| רשימת טיולים עם סינון חי | `tours.html` |
| עמוד טיול | `tour.html?id=oct7-he` |
| מורי הדרך | `guides.html` |
| פרופיל מורה דרך | `guide.html?id=uri` |
| סיור בהתאמה אישית | `custom.html` |
| מגזין וכתבה | `magazine.html`, `article.html?id=hanukkah` |
| צור קשר | `contact.html` |
| סימולציית בקשת חוות דעת | `review.html` |
| **מה השתפר (לפני / אחרי)** | `improvements.html` |

- מתג השפה בכותרת מחליף את כל האתר לאנגלית (כולל כיוון הטקסט). הבחירה נשמרת בדפדפן.
- כדי לשלוח קישור שנפתח ישר באנגלית, מוסיפים לכתובת `?lang=en`, למשל `index.html?lang=en`.
- התמונות נטענות מ-Unsplash. אם אין אינטרנט או שתמונה לא נטענת, מוצג במקומה איור נוף צבעוני, כך שהעיצוב לא נשבר.

## איך עורכים את הנתונים – `assets/js/data.js`

כל התוכן נמצא בקובץ אחד: `assets/js/data.js`. פותחים אותו בכל עורך טקסט (למשל VS Code או Notepad++).

- **פרטי העסק** (`SITE`): טלפון, מספר וואטסאפ (בפורמט `972501234567`, בלי `+` ובלי 0 בהתחלה), דוא״ל, שעות מענה וכתובות הרשתות החברתיות.
- **מורי דרך** (`GUIDES`): שם, ביוגרפיה, מספר רישיון, שפות, שנות ותק, זמן תגובה (בדקות) ותחומי התמחות.
- **טיולים** (`TRIPS`): כותרת, תיאור, מחיר, אזור, סוג, שפות, נקודת מפגש (כולל קואורדינטות למפה ול-Waze), מה כלול, ותאריכים.
- **חוות דעת** (`REVIEWS`): לפי מזהה הטיול. `r` = ציון 1–5.
- **כתבות** (`ARTICLES`).

טקסט דו-לשוני נכתב כך: `{ he: 'עברית', en: 'English' }`.

### תאריכים

תאריכים נכתבים כ-`day(14)`, כלומר 14 ימים מהיום. כך הדמו נשאר עדכני בכל יום שבו מציגים אותו.
מספר שלילי (`day(-30)`) הוא תאריך שעבר. אפשר גם לכתוב תאריך קבוע: `'2026-12-10'`.

טיול שכל התאריכים שלו עברו **לא מוצג** ברשימות. כך הדמו מדגים את הפיצ׳ר: בנתונים יש שני טיולים כאלה, "סיור סליחות" ו"חול המועד סוכות".

### ערכים קבועים (מילונים)

`region`, `type`, `interests`, `difficulty`, `duration` ותחומי ההתמחות של מורי הדרך הם מילים קבועות באנגלית. התוויות שלהן בעברית ובאנגלית מוגדרות ב-`assets/js/i18n.js`. כדי להוסיף סוג חדש, מוסיפים אותו בנתונים וגם מוסיפים תווית (למשל `type_xxx`) בשתי השפות ב-`i18n.js`.

### טקסטים של הממשק

כל הכפתורים, הכותרות וטקסטי עמוד "מה השתפר" נמצאים ב-`assets/js/i18n.js`, בעברית ובאנגלית.

## איך מעלים לאירוח חינמי ושולחים קישור

### אפשרות 1: Netlify Drop (הכי מהיר, בלי חשבון GitHub)

1. נכנסים ל-https://app.netlify.com/drop (צריך להירשם בחינם).
2. גוררים את **התיקייה `tourdeisrael-demo` כולה** לחלון.
3. אחרי כמה שניות מתקבל קישור, למשל `https://something-123.netlify.app`, ואותו שולחים לחבר.
4. בהגדרות האתר ב-Netlify אפשר לשנות את שם האתר, למשל ל-`tourdeisrael-demo.netlify.app`.

### אפשרות 2: GitHub Pages

1. יוצרים מאגר (repository) חדש ב-GitHub ומעלים אליו את **התוכן** של התיקייה `tourdeisrael-demo`, כך ש-`index.html` נמצא בשורש המאגר.
2. במאגר: **Settings → Pages → Build and deployment**, ושם בוחרים Source: `Deploy from a branch`, Branch: `main`, תיקייה: `/ (root)`, ושומרים.
3. אחרי דקה או שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

> לפני ששולחים: כדאי להחליף ב-`data.js` את מספר הוואטסאפ והטלפון במספרים אמיתיים, או להשאיר את מספרי הדוגמה ולהסביר שזה דמו.


## נגישות ונייד

- `dir="rtl"` בעברית ו-`ltr` באנגלית, עם CSS שמבוסס על logical properties, כך שאותו עיצוב עובד בשני הכיוונים.
- אין חסימה של הגדלת תצוגה (אין `maximum-scale`).
- קישור "דלג לתוכן", ניווט מלא במקלדת, מסגרת פוקוס בולטת, תגיות סמנטיות (`header`, `nav`, `main`, `article`, `dl`) ו-`alt` לתמונות.
- טפסים עם תוויות (`label`) והודעות שגיאה נגישות. כמות התוצאות בסינון מוכרזת לקוראי מסך.
- ניגודיות צבעים גבוהה (טקסט על רקע עומד ב-WCAG AA), ותמיכה ב-`prefers-reduced-motion`.
